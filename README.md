# Fortran_Experiences
Studies and experiences with Fortran.

This repository explores practical interoperability between Fortran and other languages used in scientific and engineering workflows.

## Interoperability
- C++: mixed-language integration, libraries, and build patterns
- Python: scripting, automation, data processing, and testing
- Shell: build orchestration and experiment automation

## Objectives
- Learn and experiment with modern Fortran
- Explore cross-language integration
- Build small, reproducible examples with CMake and common tooling
